# User Stories

## Recruiter
As a recruiter, I want to quickly understand Umer's experience, strengths, and projects,
so I can decide whether to shortlist him.

## Engineering Manager
As an engineering manager, I want to see depth in systems, integrations, and AI-enabled work,
so I can evaluate technical fit.

## Client
As a client, I want to see whether Umer can build production-ready systems and modern web apps,
so I can decide whether to contact him.

## Portfolio Owner
As Umer, I want a maintainable portfolio that I can expand later with more projects and content.
