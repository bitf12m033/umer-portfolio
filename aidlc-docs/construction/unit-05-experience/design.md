# Unit 05 - Experience Timeline Design

Goal:
Present professional experience clearly and credibly.

Purpose:
- Show career progression
- Highlight real-world impact
- Reinforce senior-level positioning

Experience Strategy:
- Focus on last 3–4 roles
- Highlight responsibilities and outcomes
- Keep descriptions concise

Roles to include:
1. vinSUITE (Senior Software Developer)
2. Offrs (Senior Software Developer)
3. PureLogics (Software Engineer)
4. Techleadz (Web Developer)

Structure per role:
- Company name
- Role
- Duration
- Key contributions (3–4 bullet points)
- Technologies used

UI Direction:
- Vertical timeline OR clean stacked cards
- Minimal, readable layout
- Consistent dark theme
- Clear hierarchy (company > role > details)

Constraints:
- No long paragraphs
- No fluff
- Must feel senior and impactful
