# Unit 07 - Polish, Motion, SEO

Goal:
Refine the portfolio into a production-ready, premium experience.

Purpose:
- Improve visual consistency
- Add subtle motion where useful
- Strengthen metadata and discoverability
- Ensure responsive and accessible presentation

Scope:
- Section spacing consistency
- Hover and entrance animations (subtle only)
- Smooth scrolling
- Metadata in app/layout.tsx
- Improved button/link states
- Responsive cleanup
- Accessibility basics

SEO Direction:
- Clear metadata title
- Strong metadata description
- Relevant keywords
- Open Graph basics if appropriate

UI Direction:
- Dark AI-themed
- Professional and restrained
- No flashy or distracting effects

Constraints:
- No major structural rewrites
- No unnecessary animation libraries unless already desired
- Keep performance strong
