# Unit 04 - Projects Design

Goal:
Showcase real-world work as proof of capability.

Purpose:
- Demonstrate full-stack engineering ability
- Highlight system design and integrations
- Emphasize AI-enabled work
- Show business impact

Project Strategy:
- Focus on 3–4 strong projects (not many weak ones)

Selected Projects:
1. Minutes – Real-Time Collaboration (AI + SaaS)
2. Offrs Marketing Applications (automation + APIs)
3. Lead & Deal Reporting System (backend + integrations)
4. Shopify Migration (optional support project)

Structure per project:
- Title
- Short description
- Key features
- Tech stack
- Your role / contribution
- Impact (if possible)

UI Direction:
- Card-based but premium
- Expandable or detailed view
- Clean layout (not crowded)
- Dark theme consistent

Constraints:
- No generic cards
- No long paragraphs
- Must feel senior-level
