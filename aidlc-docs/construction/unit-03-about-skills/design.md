# Unit 03 - About & Skills Design

Goal:
Establish credibility and clearly communicate expertise.

Purpose:
- Show professional experience (8+ years)
- Highlight full-stack capability
- Emphasize AI-integrated systems work
- Present skills in structured, readable format

About Section:
- Short, strong paragraph (not long)
- Focus on:
  - experience
  - systems built
  - real-world impact
  - AI usage

Skills Section:
Grouped (not a long list):
- Frontend
- Backend
- AI / Automation
- Integrations
- Tools / Cloud

UI Direction:
- Clean grid layout
- Cards or grouped sections
- Dark theme consistent with Hero
- Minimal icons (optional)

Constraints:
- No dumping all skills blindly
- No long paragraphs
- Must feel senior-level, not junior
