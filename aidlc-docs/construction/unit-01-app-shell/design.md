# Unit 01 - App Shell Design

Goal:
Create the base layout for the portfolio application.

Components:
- Navbar
- Footer
- SectionWrapper

Design Decisions:
- Next.js App Router used
- Tailwind CSS for styling
- Dark AI-themed UI (minimal, professional)
- Modular component structure

Reasoning:
- Reusability across sections
- Clean separation of concerns
- Scalable structure for future units
